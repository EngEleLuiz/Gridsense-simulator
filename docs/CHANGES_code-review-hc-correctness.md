## Results impact

- **Unbalanced stochastic studies must be re-run.** Their `total_pv_mw` / `hc_mw` used the wrong definition (CR-08). On a fixed test seed the old value was 0.098 MW and the correct α-quantile of total PV was 0.131 MW. Any scenario that reached the search cap was also recorded as a finite capacity (CR-07). `hc_lambda` (kWp per adopter) changes only when censored scenarios are present.
- **Unbalanced deterministic numbers are unchanged.** This covers the Phase 7.4 table (for example, 2.78 and 5.34 kWp per customer off-peak under EN 50160). The IEEE European LV customers are all single-phase, so S-08 does not change their PV placement.
- **Duration (QSTS) studies:** the annual `lambda_max` is unchanged. The following outputs can change:
  - `window_lambda_quantiles` now excludes censored windows, and `n_windows` counts only windows with an exceedance.
  - `lambda_fail` and `resolved` can change in the rare case where the binding threshold has no bracket. Such rows become non-comparable in the dbt staging model.
- Runs that hit an isolated bus or a solver data error were previously recorded as bounded or `baseline_infeasible`. They now raise `baseline_infeasible` (isolated bus) or `error`.
- The payload `schema_version` is unchanged (2). New fields are additive: `n_censored`, `hc_mw_ci_low`/`hc_mw_ci_high` and `n_adopters` (unbalanced stochastic), and `n_windows_censored` (duration quantiles).
